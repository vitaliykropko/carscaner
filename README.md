# Mazda 6 GH | OBD-II Scanner PWA

Прогрессивное веб-приложение (PWA) для диагностики, чтения параметров в реальном времени и логирования ошибок автомобилей **Mazda 6 GH (2007–2012)** через адаптер **ELM327**.

---

## 🌟 Основные возможности

1. **Диагностика ошибок (DTC):**
   - Чтение подтвержденных кодов неисправностей (**Mode 03**).
   - Чтение ожидающих кодов (**Mode 07 - Pending**).
   - Чтение постоянных кодов (**Mode 0A - Permanent**).
   - Сброс ошибок (**Mode 04**) с подтверждением и гашением индикатора Check Engine.
   - Поддержка адресных заголовков шины CAN Mazda 6 GH:
     - `0x7E0` — Блок управления двигателем (**PCM**)
     - `0x7E1` — Блок управления АКПП (**TCM**)
     - `0x760` — Система динамической стабилизации и тормозов (**ABS / DSC**)
     - `0x730` — Электроусилитель руля (**EPS**)
     - `0x720` — Комбинация приборов (**IC**)
     - `0x726` — Блок кузовной электроники (**BCM**)
   - Встроенная база расшифровки кодов на русском языке с указанием частых "болячек" Mazda 6 GH (P0421, P2187, P0328, C1278 и др.) и рекомендациями по устранению.
   - Экспорт полного отчета по диагностике в текстовый файл (`.txt`).

2. **Приборная панель и датчики (Dashboard):**
   - Аналоговые спидометр и тахометр на Canvas с анимацией стрелок и красной зоной.
   - Живые цифровые показатели:
     - Температура охлаждающей жидкости (ОЖ, °C)
     - Расход воздуха (MAF, г/с)
     - Положение дроссельной заслонки (%)
     - Нагрузка на двигатель (%)
     - Температура впускного воздуха (IAT, °C)
     - Краткосрочная и долгосрочная топливные коррекции (STFT / LTFT, %)
     - Уровень топлива (%)
     - Напряжение бортовой сети (АКБ, `AT RV`)
   - Интерактивный самописец (Realtime Strip-Chart) с выбором метрики и автоматическим масштабированием.

3. **Логирование телеметрии (Flight Recorder):**
   - Непрерывная запись параметров поездки в буфер.
   - Экспорт в **CSV (Excel)** с поддержкой русской кодировки (UTF-8 BOM).
   - Экспорт в **JSON** для дальнейшего анализа.
   - Таблица последних значений в реальном времени.

4. **Прямой терминал AT / PID:**
   - Отправка любых «сырых» команд в ELM327 (`AT Z`, `AT RV`, `0100`, `AT SH 760`, и т.д.).
   - Быстрые кнопки для популярных команд.
   - Цветовая дифференциация отправленных (TX) и принятых (RX) пакетов.

5. **Режим симулятора (Demo):**
   - Возможность протестировать приложение, циферблаты, чтение/сброс ошибок и экспорт логов прямо сейчас на компьютере или телефоне без подключения к машине!

---

## 📱 Режим PWA (Установка на телефон и ПК)

Приложение является полноценным **Progressive Web App (PWA)**:
- Работает автономно (Offline) благодаря Service Worker.
- Устанавливается как нативное приложение на экран «Домой» смартфона или рабочий стол ПК.
- Поддерживает полноэкранный режим (Standalone) без адресной строки браузера.

---

## 🚀 Как запустить приложение

### Вариант 1. Быстрый запуск на ПК (Windows):
1. Дважды кликните по файлу **`start.bat`** (или выполните команду `python server.py`).
2. В браузере (Chrome / Edge) автоматически откроется страница:
   ```
   http://localhost:8000
   ```
3. Для установки нажмите кнопку **«📱 Установить»** в шапке сайта или иконку установки в адресной строке браузера.

### Вариант 2. Запуск на смартфоне (Android / iOS):
1. Запустите сервер на ПК: `python server.py`.
2. Убедитесь, что телефон и ПК подключены к одной Wi-Fi сети.
3. Откройте в браузере Chrome на телефоне: `http://<IP-адрес-компьютера>:8000` (например, `http://192.168.1.50:8000`).
4. Нажмите в меню браузера **«Добавить на главный экран»** (или «Установить приложение»).

## 🔌 Как подключиться к ELM327

### 1. Подключение через Web Serial (Рекомендуется для ПК / Ноутбука):
- **Для USB-адаптера**: Вставьте кабель в разъем USB.
- **Для Bluetooth-адаптера**:
  1. Выполните сопряжение ELM327 в настройках Bluetooth Windows (PIN: `1234` или `0000`).
  2. Windows создаст виртуальный входящий/исходящий COM-порт.
  3. В приложении нажмите **«⚡ Подключить»** -> **«Web Serial»**.
  4. В появившемся окне браузера выберите соответствующий COM-порт.

### 2. Подключение через Web Bluetooth (BLE 4.0+):
- Используется для современных адаптеров с поддержкой Bluetooth Low Energy (например, *Vgate iCar Pro BLE*, *Veepeak BLE*, *Kingbolen*).
- В приложении выберите **«⚡ Подключить»** -> **«Web Bluetooth»** и выберите найденное устройство из списка.

### 3. Где находится разъем OBD-II в Mazda 6 GH:
- В салоне автомобиля, под рулевой колонкой с левой стороны (рядом с рычагом открывания капота).
- Перед подключением включите зажигание в положение **ON** (или заведите двигатель).
